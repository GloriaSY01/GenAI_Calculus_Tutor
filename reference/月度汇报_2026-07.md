## 一、项目概览

选题为面向大学微积分的 GenAI 学习伴侣，整体由三部分组成，也是本次汇报的主线：

1. **Learning Content Generation（学习内容生成）**：自动生成结构化、可调难度、可验证的题目与解析。
2. **AI Agent Design（苏格拉底式导师）**：引导学生自己想出答案，不直接剧透。
3. **Student-System Interaction（学生-系统交互）**：前台交互、防作弊/防越狱、学习分析与反馈闭环。

**预期成果**：一个可用的 AI 辅助微积分学习系统 + 教育 AI 方向的研究贡献 + 约 1–2 篇论文。

> 详见 [设计文档](../docs/ARIN7600_Capstone_Design.pdf)。

## 三、Demo 演示（现场跑通）

技术栈：FastAPI（后端）+ Streamlit（前端）+ OpenAI 兼容 API。按三部分逐一演示：

### 3.1 内容生成
- 支持 **4 种题型**：单选、多选、填空、拖拽排序（过程型练习）。
- 覆盖 **7 个 Calculus 1 知识点**、**3 档难度**（easy / medium / hard）。
- 自动评分；标准答案保存在后端，前端只下发 public question（防泄题）。

### 3.2 苏格拉底式导师
- 不直接给答案，一步步引导学生推理。
- 两种模式：**自由提问（free chat）** 与 **关联左侧题目**。
- explain-to-unlock：鼓励学生先解释思路，再推进下一步。
- 内置 A/B 条件（explain / control），为后续实验做准备。

### 3.3 学生-系统交互层
- 左右两块布局：左侧练习作答 + 右侧助教对话。
- 学生视图 vs 教师调试视图（`?instructor=1`）。
- 防越狱 guardrail：拦截“忽略指令、直接要答案”等 gaming 行为。
- 全流程交互日志埋点，为学习分析提供数据。

> 仓库结构与运行方式见 [README（中文）](https://github.com/GloriaSY01/GenAI_Calculus_Tutor/blob/main/README.zh-CN.md)。

## 四、文献调研（精简，按方向归纳）

不逐篇罗列，按“支撑哪个模块 + 借鉴什么”归纳为两条主线（文献调研与量化指标合为一份文档，详见 [文献调研 + 量化指标](<../docs/AR7600 量化指标体系 .pdf>)）：

**导师 Agent 方向**
- Socratic 教学分阶段（review / heuristic / rectify / summarize）
- RAG 知识增强，减少幻觉
- tutor 教学能力评估、逐轮回复验证
- 认知参与度分析、个性化教学策略

**内容生成方向**
- 可解 / 答案正确 / 教育适当 三大硬标准
- plan-evaluate-optimize 迭代出题
- 多 Agent 协作 + 五维元评估
- CAS/形式化逐步验证、干扰项质量、变体题鲁棒性

## 五、量化指标体系

已把“参与度 / 学习分析”的构想落成**可计算指标**（与文献调研同属一份文档，详见 [文献调研 + 量化指标](<../docs/AR7600 量化指标体系 .pdf>)）：

- **导师模块**：单轮输入质量、认知参与等级、解释深度、教学策略有效性、错误概念诊断等。
- **内容生成模块**：数学正确性、答案一致性、干扰项有效性、一次通过率 / 产出率、题库覆盖度等。

**当前 demo 已可直接报告的 baseline**：

| 项 | 现状 |
| --- | --- |
| 支持题型 | 4 类（single / multiple choice、fill blank、drag order） |
| 支持知识点 | 7 类 Calculus 1 topic |
| 支持难度 | 3 档（easy / medium / hard） |
| 隐藏标准答案 | 是（答案存后端） |
| 自动评分 | 是（四类题型均支持） |
| Tutor 联动 | 是（`to_problem()` 转为 Tutor 可用题目） |
| 外部 CAS 验证 | 暂未实现，下阶段扩展 |
