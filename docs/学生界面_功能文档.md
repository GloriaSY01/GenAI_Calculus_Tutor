# 学生界面 · 功能文档（Student Page）

对应文件：`frontend/streamlit_app.py`
共享模块：`frontend/api.py`（后端调用）、`frontend/ui.py`（主题）、`frontend/i18n.py`（中英文）

本次改版目标（对应评审 Jon 的反馈）：让**初学者**也能上手——知道从哪开始、下一步学什么、怎么练、卡住怎么办；页面**从上到下**单向阅读，去掉左右并列造成的困惑；视觉统一、支持中英文切换。

---

## 0. 视觉与全局

### 0.1 配色与排版（教育风格）
- 主色 **学习蓝 `#2563EB`**（主按钮、进度条、当前步骤高亮）
- 辅助 **琥珀 `#F59E0B`**，状态色 绿/红 用于正确/错误反馈
- 背景为浅蓝中性色，卡片为白色圆角（圆角 18px + 轻阴影），层级清晰
- 标题用衬线字体 `Fraunces`，正文用 `Inter`，阅读舒适
- 所有可点击元素有 hover 微动效（上移 1px），符合可用性规范

### 0.2 语言切换（右上角）
- 页面右上角有 `EN / 中文` 分段控件（`segmented_control`）
- 切换后整页文案即时刷新；语言状态存于会话，跨页面（学生页/教师页）一致
- 文案集中在 `frontend/i18n.py`，`t("key")` 取当前语言字符串

## 2. 学习路径条（Learning Path）— 核心新增

**解决的问题**：初学者不知道该学哪个 topic、先后顺序是什么。

| 功能点 | 说明 |
|---|---|
| 步骤展示 | 横向展示 7 个知识点步骤，来自后端 `GET /learning-path` |
| 每步信息 | 序号、标题、一句话简介（如“极限是一切的基础”） |
| 先后顺序 | 按先修依赖排序：极限 → 连续 → 导数 → 链式法则 → 导数应用 → 相关变化率 → 积分 |
| 当前高亮 | 正在学习的步骤用蓝色高亮，按钮显示 `● 学习中` |
| 切换学习 | 点击任一步骤的 `开始` 即切换当前知识点，并清空上一题状态 |

**交互流程**：进入页面 → 默认停在第 1 步（极限）→ 学生可按顺序推进，也可自由跳转。

## 3. 当前知识点区块（Step 区）

选定知识点后，页面展示该步骤的标题、简介与“建议先学”的先修知识点，帮助学生判断自己是否具备基础。

随后是**从上到下**的三步引导：

### 3.1 ① 设置练习
| 控件 | 功能 |
|---|---|
| 难度滑块 | `easy / medium / hard`，默认 easy（对初学者友好） |
| 题型选择 | 单选 / 多选 / 填空 / 步骤排序（`i18n` 本地化标签） |
| 生成题目按钮 | 调用 `POST /generate`，按当前知识点+难度+题型出题；生成时显示加载态 |

### 3.2 ② 作答
- 顶部显示题目元信息：`知识点 · 难度 · 题型`
- 题干用 Markdown/LaTeX 渲染
- 按题型渲染作答控件：
  - **单选**：单选按钮（`$` 符号会被清理，公式显示更干净）
  - **多选**：多个复选框，提示“选择所有正确项”
  - **填空**：按空格数量渲染多个输入框
  - **步骤排序**：可拖拽排序组件（`streamlit_sortables`）
- `提交答案` 调用 `POST /grade`，服务端判分：
  - 正确 → 绿色成功提示 + 解析
  - 错误 → 红色提示 + 解析 + “可向下滚动让助教讲解”的引导

### 3.3 ③ 获取引导
- 一键 `就这道题向助教提问`：把当前题目链接给下方 Tutor（`session/start` 带 `problem_id`）
- 已链接时显示“助教正在帮你解决这道题”

**未生成题目时**：显示空状态提示，引导学生先选难度/题型并生成。

## 4. 助教对话区（Tutor）

| 功能点 | 说明 |
|---|---|
| 默认自由对话 | 进入即自动建立自由对话会话（`session/start` 不带题目） |
| 题目联动 | 从 ③ 链接题目后，围绕该题苏格拉底式引导；顶部显示“正在帮助你解决 …” |
| 自由/联动切换 | 联动时提供 `自由提问` 按钮切回自由对话 |
| 进度条 | 只显示鼓励型进度（`mastery`），**隐藏** condition / hint level / reasoning 等实验内部字段 |
| 里程碑提示 | 解出后提示“你自己想出了答案”；触发护栏时温和提示不直接给答案 |
| 对话记录 | 聊天气泡展示历史，用户/助教区分 |
| 输入区 | 文本框 + `发送`，提交后调用 `POST /session/{id}/message` |

**实验设计仍在后台静默进行**：`explain` / `control` 条件随机分配并写入日志，供研究分析，但学生界面不暴露。

## 5. 复用与改动说明

- **复用**（沿用原有后端能力）：题目生成、四种题型作答、服务端判分、Tutor 会话与消息、explain/control 随机分配与日志。
- **改动**：
  - 布局由“左右两块并列”改为“单列、从上到下 1→2→3 + 底部助教”，阅读顺序明确。
  - 新增学习路径条，面向初学者做引导。
  - 统一教育风格主题（`ui.py`）。
  - 全页中英文切换（`i18n.py` + 右上角控件）。
  - 移除学生页的教师/实验内部信息展示（原 `?instructor=1` 相关内容迁至独立教师页）。

## 6. 依赖的后端接口

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/topics` | 知识点列表 |
| `GET` | `/learning-path` | 推荐学习顺序（学习路径条） |
| `POST` | `/generate` | 生成题目 |
| `POST` | `/grade` | 判分 |
| `POST` | `/session/start` | 建立助教会话（自由或联动题目） |
| `POST` | `/session/{id}/message` | 发送学生消息，获取助教回合 |

---

## 7. 可用性 / 无障碍要点（已遵循）

- 主按钮全宽、圆角、清晰 hover，触达面积充足
- 反馈就近显示（判分结果紧跟题目；错误伴随解析与下一步引导）
- 颜色不作为唯一信息载体（正确/错误同时有文字与图标语义）
- 正文字号与行距适中，卡片留白清晰，信息分组明确
- 文案双语，母语学生降低理解门槛
