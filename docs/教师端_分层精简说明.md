# 教师端分层精简

日期：2026-11-07。基于 React 教师端调整界面，未修改学生端和后端统计公式。

## 默认展示

- 班级概览：参与学生估算、练习提交次数、提交正确率。
- 知识点表现：正确率和答对/提交数量，默认展示前五项，其余展开查看。
- 优先排列至少五次提交的知识点，再按正确率升序排列。五次是展示规则，不代表统计显著性；小样本显示提示，不作掌握程度判断。

## 按需展开

- 更多量化指标：全部与各难度下的未记录本题 AI 帮助 / 已获得 AI 帮助 / 帮助状态未知的提交正确率、对应提交数、模型评估的推理分布。
- 空数据展示（2026-11-08）：展开后仍展示全部难度、简单、中等、困难以及三种帮助状态；无提交的格子显示 `— (0)`。五级推理标签始终保留，无有效对话时显示 `—`，同时标明有效轮次为 0 和暂无数据。部分分组有数据时，其他维度也继续保留；真实有样本但全错仍显示 `0% (样本数)`。
- 练习配置：保留题型、难度、数量、模板、创建和删除。作业分发与完成率仍未接通，界面保留说明。
- 教学助手继续保留；点击知识点提供提问上下文，切换班级清空助手历史。

## 删除与口径

移除重复摘要、学习态度判定、gaming/拦截指标、重复的会话知识点诊断与研究条件视图；无真实记录不展示示例图。

参与人数沿用后端现有计算，明确标记为估算。练习正确率按已判分提交计算，包含重试与章节挑战，不是首次正确率或班级掌握率。AI 辅助分类存在会话时间顺序的已知限制，因此放入详情并注明不能作效果对照。无分母显示“—”。

数据范围为当前班级全部已记录数据；本次没有增加时间筛选、实验隔离或新的过程指标。相关数据方案见《首轮实验_数据采集与师生端指标对应方案》。

## 验证

Vite 构建通过。隔离浏览器使用合成接口数据验证默认折叠、比例及样本数、知识点关联助手、练习配置创建、班级切换、空数据、中英文、深色移动布局及接口错误。未写入真实班级记录。
