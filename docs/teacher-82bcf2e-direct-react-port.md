# 82bcf2e 教师端直接迁移到 React

## 基准与范围

用户要求保留 `82bcf2e245c8c22ff56e831927d8aa7cb33e96d7` 的教师端设计，只替换 Streamlit 实现。本次实现替代此前自行重组为三个 React 页面的方案。

## 保留内容

- 原版单页长面板、左侧目录、班级摘要、三个步骤和七个子目录锚点。
- 顶部教师仪表盘、教师账号输入框、固定 A/B 班选择、角色/主题/语言设置。
- 双语文案、浅色与深色样式从原提交直接提取至 legacy82.json 和 legacy82-dark.json。
- 班级摘要的关注知识点、数据依据、建议及无数据分支。
- 第一步的四项 KPI、做题成绩、按难度图表、全部教材知识点选择、四项知识点成绩、学习态度及旧版洞察阈值。
- 第二步的 3:2 布局、知识点健康度、五级推理分布、完整表格、自由对话注释及可选解释回应率、研究条件视图。
- 第三步的 3:2 新任务/当前任务、薄弱点预填、三种原始模板、清除预填、最多八个题块、题型/难度/数量、题量和时间估算、备注、创建与删除。
- 无真实数据时的原版示例图数值和提示，顶部 KPI 缺省 0 / 0% 行为。
- 原版问 AI 抽屉、通用及知识点建议、知识点同步、会话记录、离线标识和清空。

## React 替代层

LegacyDashboard.jsx 替代原页面编排及模块；legacy82.css 替代 Streamlit 容器和控件布局。Altair 改用已有 ECharts，保留原数据、顺序、颜色、图例和展示形式。渲染器、字体和原生控件仍可能存在细微像素差异，不宣称逐像素一致。

教师专用 API 直接调用现有后端，保留原版失败反馈。学生入口在当前 React 应用内返回学生页面，无需启动 Streamlit。学生端与后端计算规则不变。

## 验证

隔离浏览器验证通过：原版各标题同时在单页、七个子目录、KPI、作业预填/清除、发布失败/成功、班级归属、助手知识点联动、双语文案、原版示例图、390px 无整体横向溢出、后端失败、无运行异常。

使用合成数据，不写真实班级记录。脚本与截图在 tmp/teacher-legacy-check.cjs、tmp/teacher-legacy82-*.png。

Streamlit 文件保留供追溯，不是当前教师端运行依赖。此前自行重组的临时教师模块已移除。
