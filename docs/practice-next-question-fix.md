# Practice 下一题重复修复

日期：2026-09-15。

## 原因

前端没有传递练习历史；后端随机抽教材题时没有排除已见题目。模型调用异常时后端使用固定模板，前端请求失败时还会返回固定演示题。这些路径都可能让下一题看起来完全没有变化，即使题目 ID 已更新。

## 修改

- 前端按知识点、题型、难度和语言记录最近 50 个题干，通过 `exclude_stems` 传给出题接口。记录保存在当前 Practice 组件内，刷新或离开后不持久化。
- 教材题筛选排除已见题干；模型收到避免重复的要求，相同题干最多尝试生成两次。
- 新题生成失败时优先使用尚未出现的教材题，否则显示失败提示，不再用固定演示题假装生成成功。首题原有的后端离线模板仍保留。
- 获取新题失败后保留现有题目和作答结果；切换条件时忽略过期出题响应，并在语言变化时重新取题。
- 去重使用去空格、大小写和美元符号后的题干比较，尚不保证语义相同但措辞不同的题目被识别。

## 验证

`tests/test_question_repetition.py` 和 `tests/test_generator.py` 共 10 项测试通过，覆盖教材题去重、模型重复后重试、持续重复和模型离线情形。前端生产构建通过，存在既有的包体积提示。
