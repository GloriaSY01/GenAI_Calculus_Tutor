# 教师端内容迁移至 React

> 本文的重组方案已被替代。用户要求原封保留 82bcf2e 设计，最新实现以 teacher-82bcf2e-direct-react-port.md 为准。

## 目标与范围

以 `82bcf2e` 的 Streamlit 教师端内容为依据，在当前 React 工作台恢复教学摘要、练习表现、学习行为、知识点诊断、推理质量及混合题型作业配置。

保留当前 React 三个导航页面，分别承载旧版的概览、诊断和行动内容；并非逐像素复制 Streamlit 长页面。学生端与后端统计逻辑不变。

## 页面与数据

- 总览：关注知识点、证据与下一步建议；参与学生、练习提交、独立作答正确率、AI 辅助作答正确率；按难度对比两种作答方式；按知识点查看提交及正确情况；AI 求助比例、应付信号、拦截比例及班级洞察。
- 诊断：按辅导解题率排序的知识点健康度、可展开完整表格、未关联自由对话数量；固定五级顺序的推理分布；后端有数据时展示解释回应率与教学条件研究视图。
- 布置练习：保留混合题型题块和三种模板；根据薄弱知识点预填模板，匹配规则沿用旧版：低于 40% 使用基础模板，40% 至 70% 使用综合模板，超过 70% 使用挑战模板。
- 保留班级选择、语言与主题切换、浮动教学助手。

统计数据来自 GET /analytics/class。API 转换层额外保留原始 teacher 数据，避免丢失旧版使用的 practice、条件对比及可选字段。教师分析接口失败时显示错误及重试，不回退为模拟班级指标。

## 与旧实现的有意差异

- 无真实数据时显示空状态，不自动插入旧版的示范图表。
- 无独立或辅助提交时对应正确率显示“—”，与真实 0% 区分。
- 不再挂载当前 React 版本中的演示 Quiz scores 模块；它不能替代旧版练习表现统计。
- 洞察区域、知识点图表设置内部滚动，长表格支持横向滚动。
- 作业发布失败后保留输入并解除等待状态；删除增加确认及错误反馈；修正异步知识点加载后的默认题块，并检查题量范围。
- 学习态度采用旧版客户端洞察阈值：优先使用至少 3 次会话的知识点；薄弱解题率低于 60%；应付信号 30% 为较高；推理评分低于 1.5 或至少 3 时产生提示；会话少于 5 次时提示样本不足。
