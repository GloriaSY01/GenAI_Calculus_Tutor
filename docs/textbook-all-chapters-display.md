# 学生端全章节插图与公式排版

更新日期：2026-09-15。

## 完成范围

- 覆盖现有第 1–8 章、51 个小节。
- 从章节 PDF 中提取到 186 个独立图像对象。保留第一章原先人工校对的 8 张裁图，替代其中 6 个对象（两组图拆成左右子图），最终页面使用 188 张独立插图。
- 插图显示在对应概念说明下，附描述性图注，可点击查看原图。原有例题的精确关联保留；其余图片配有单独的简短概念说明，按教材页码排列，避免仅因同页就挂到不相关的例题下面。
- 150 个教材内容块的 378 条独立公式使用 LaTeX，并整理了正文中的 155 处行内数学表达。分数、积分、根号、上下标等由 KaTeX 排版。

## 实现与维护

`backend/rag.py` 在展示层合并插图清单、说明、正文和公式覆盖数据，不重建向量索引。新增数据为 `extracted_figures.json`、`illustration_notes.json`、`formula_overrides_remaining.json`、`text_overrides.json` 和 `figure_caption_overrides.json`；第一章继续使用已有的 `formula_overrides.json`。

前端为插图概念块增加分隔和留白，限制图片高度并保持比例。说明及图注是教材整理笔记，不宣称为教材逐字原文。图中原有英文标签和栅格公式仍保留原图；本次 LaTeX 转换针对页面文字公式。

图片可通过项目根目录下的以下脚本复现，需要 pypdfium2 和 Pillow，以及原始章节 PDF：

```powershell
python -m scripts.extract_textbook_figures
python -m scripts.restore_textbook_figures
```

生成的图片资源位于被 Git 忽略的解析目录；新克隆环境需要重新生成或同步这些资源。修改展示数据后，如服务没有自动重载，需要重启后端以清除缓存。
